# Purple Dynasty RP — сайт SA-MP сервера

**PD = Purple Dynasty** («Пурпурная династия»). Тёмный «дорогой» лендинг: фиолетовый, серебро, чёрный и белый.

Что на странице:

- **3D-логотип PD со сканером-интроскопом.** Хромовые буквы Anton вращаются за курсором. Наведи — линза «просвечивает» логотип, как досмотровый рентген: внутри пачки денег, Glock 17, AK-47, бронежилет, магазины, граната и секретный бургер Биг Смоука. Найди всё — получишь «Контрабанда найдена». На телефоне — касание и автоскан.
- **Манифест**, который «загорается» по словам при прокрутке.
- **Роли** (Мафия, Vinewood, Red County) — твои картинки в фиолетовом дуотоне, под курсором проявляется цвет.
- **Ивенты** — карусель как на референсе: тянешь, карточки разворачиваются в 3D, на фоне огромная дата, живой обратный отсчёт до старта.
- **Как начать** — две вкладки (лаунчер / вручную), шаги с галочками и кольцом готовности.
- Пасхалки: `HESOYAM` — денежный дождь, `AEZAKMI` — снять розыск, `DYNASTY` — логотип делает два оборота. Шесть быстрых кликов подряд — растёт «уровень розыска». Копирование IP — «Миссия пройдена!».

## Что поменять под свой сервер

Всё — в одном файле `js/config.js`:

| Поле | Что это |
|---|---|
| `serverAddress` | IP и порт, например `51.195.126.182:7777` |
| `launcherUrl` | ссылка на лаунчер: `https://...` или файл на сайте `files/PurpleDynasty.exe` |
| `launcherNote` | подпись под кнопкой (размер, ОС) |
| `onlineApi` | API open.mp для онлайна (сервер должен быть в списке open.mp); `null` — не показывать |
| `socials` | ссылки на VK, Telegram, Discord, YouTube |
| `EVENTS` | ивенты: название, текст, дата, расписание, фото |

Расписание ивента: `{ type: 'yearly', month: 10, day: 31, hour: 20, durationHours: 6 }` — раз в год,
`{ type: 'weekly', weekday: 5, hour: 22, durationHours: 3 }` — каждую пятницу (0 — воскресенье). Отсчёт и «Идёт сейчас» сайт считает сам.
Время — серверное, по Москве (`SERVER_UTC_OFFSET_MINUTES = 180` в начале списка): игрок из Новосибирска увидит верный отсчёт до 22:00 МСК.

Тексты ролей, фактов и шагов — прямо в `index.html`.

## Шрифт

Весь сайт набран одним семейством **PD Display**: латиница и цифры — **Anton** (шрифт с референса), кириллица — **Oswald Bold** того же автора (Vernon Adams), потому что в Anton нет русских букв. Оба шрифта бесплатные (SIL Open Font License), лежат в `fonts/`. Логотип собран из настоящих контуров букв Anton.

## Фото ивентов

Фото взяты из каталога Openverse с лицензиями CC0 / Public Domain и подключены прямыми ссылками. Для надёжности лучше скачать их в `img/events/` и поменять ссылки в `EVENTS`.

## Запуск и публикация

Сайт на ES-модулях, поэтому открывать `index.html` двойным кликом нельзя — нужен любой веб-сервер:

```bash
npm start
```

и открыть http://localhost:8080. Перед публикацией впиши полный адрес картинки-превью в `index.html`:
`<meta property="og:image" content="https://твой-домен/img/og.jpg">` — соцсети и мессенджеры не понимают относительные ссылки.

Публиковать можно на любой статический хостинг (GitHub Pages, Netlify, Cloudflare Pages, обычный nginx): загрузи `index.html` и папки `css`, `js`, `img`, `fonts`, `vendor`.

После `npm install` библиотеки и шрифты копируются командой `npm run vendor` (уже сделано, папки на месте). Тесты вспомогательных функций: `npm test`.

## Оптимизация

- three.js грузится отдельно и не мешает остальной странице; если WebGL недоступен — показывается статичный логотип.
- 3D-сцена ставится на паузу, когда логотип за экраном или вкладка скрыта; на телефонах — пониженное разрешение.
- Поддержка «уменьшить движение» (prefers-reduced-motion).
